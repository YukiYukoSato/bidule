Bienvenue sur le site de mini-jeux Mécanique Poids Lourd

Ce site propose des mini-jeux interactifs pour réviser la mécanique des poids lourds : systèmes de freinage, moteurs diesel, transmission, diagnostic de pannes...

Certains jeux sont plutôt accessibles pour réviser les bases, d’autres sont volontairement plus difficiles pour se challenger comme en situation réelle d’atelier.

Comment utiliser ce site ?

1. Clique sur Mini-jeux pour afficher la liste des jeux.
2. Choisis un mini-jeu (Quiz, Diagnostic, Mémo...).
3. La page se transforme pour n’afficher que ce jeu, avec un bouton ← Mini-jeux pour revenir à la liste.

Le score global en haut à droite additionne les points gagnés dans tous les mini-jeux.
